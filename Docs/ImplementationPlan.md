## 적용한 기획 (현재 구현)

- 장르: **오버쿡드형 캐릭터 운반 + 모듈 칩 슬롯 + VRAM 효율**
- 핵심 루프: 라운드 시작 → 목표 손님 응대 → 칩 생산(VRAM 소모) → 라운드 정산 → 다음 라운드
- 조작: WASD 이동, Z 상호작용(빈 곳이면 바닥 내려놓기/집기, 찬 슬롯이면 칩 스왑), C 대시, X 들여다보기
- 진행: **r00 실습 튜토리얼**(단계 잠금·인내심 스킵) → r01~r06
- VRAM: 생산마다 소모, 초과 시 느림(소프트), 정산에서 효율·예산 점수
- 결과 연출: 칩 태그·점수 기반 절차적 CSS 프리뷰(실모델/API 없음)
- 제외: 실모델/API, 포트 드래그 DAG, 칩 상점, 라이프/E키

## 구조

1. `KitchenSession`이 운반·손님·슬롯·생산·VRAM 규칙을 담당한다.
2. `KitchenScene`(Phaser)이 이동·스테이션·상호작용·가이드 화살표를 담당한다.
3. `TutorialGuide`가 r00 단계 잠금만 담당한다(세션 규칙 최소 침습).
4. HTML UI가 메뉴·HUD·해금 모달·정산·세이브를 담당한다.
5. r00~r06 해금은 선반 칩 목록과 동기화한다.
