## 완료 전 검증

1. `npm install` 후 typecheck, test, build를 실행한다.
2. Chrome/Edge에서 WASD·E로 O01 완주(주문→입력→칩→생산→전달)를 확인한다.
3. 잘못된 손님 전달 거절, 인내심 이탈, 다음 의뢰 해금을 확인한다.
4. GitHub Pages Source를 GitHub Actions로 설정하고 배포 URL을 확인한다.
