## 완료 전 검증

1. `npm install` 후 typecheck, test, build를 실행한다.
2. Chrome/Edge에서 새 게임 → r00 튜토리얼 완주(주문서→입력→칩→슬롯→생산→출구→전달)를 확인한다.
3. r01에서 WASD·Z(바닥 내려놓기 포함)·C·X, 잘못된 손님 전달 거절, 인내심 이탈을 확인한다.
4. 모듈 해금 모달·라운드 정산·새로고침 후 세이브 복구를 확인한다.
5. GitHub Pages Source를 GitHub Actions로 설정하고 배포 URL을 확인한다.
