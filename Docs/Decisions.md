# Decisions

## 2026-08-03 (손님 머리 위 프롬프트)

- 손님 요청 문구는 카운터 머리 위에 **한 줄 말풍선**으로 보여 준다. 주문서를 집으면(`orderTaken`) 숨긴다.
- 긴 프롬프트는 말줄임 처리하고, 들고 있는 주문서의 X 들여다보기는 그대로 유지한다.

## 2026-08-03 (모듈 해금 튜토리얼 위젯)

- 라운드 시작 시 아직 소개하지 않은 해금 칩이 있으면 우측 하단 위젯으로 설명한다.
- 문구 형식: `이건 ~~한 모듈입니다.` (`ModuleDefinition.unlockTutorial`)
- `introducedModuleIds`를 세이브에 저장해 같은 모듈 설명을 반복하지 않는다. 기존 v2 세이브는 빈 배열로 호환.

## 2026-08-03 (시뮬 프리뷰 강화)

- 실제 LLM/이미지 API는 쓰지 않는다. 칩 태그·품질 점수 기반 **절차적 CSS 프리뷰**를 강화한다.
- `previewKey`에 품질 밴드(`lo|mid|hi`)를 포함해 같은 태그라도 점수에 따라 노이즈·선명도가 달라지게 한다.
- 들여다보기(X)에서 적용 효과 목록과 주제/스타일/구도/선명 점수를 함께 보여 주문서↔결과 비교를 돕는다.

## 2026-08-02 (바닥 내려놓기)

- 주변에 스테이션/손님이 없을 때 `Z`로 들고 있는 주문서·모듈 칩·이미지를 바닥에 내려놓을 수 있다.
- 손이 비어 있을 때만 바닥 물건을 상호작용 대상으로 잡는다(들고 있을 때는 근처 바닥 물건이 있어도 내려놓기 가능).
- 손님이 이탈하면 그 손님의 주문서/이미지가 바닥에 있어도 함께 제거한다. 모듈 칩은 유지.

## 2026-07-31 (라운드·VRAM·효율 점수)

- 플레이를 **라운드 단위**(R01~R06)로 운영한다. 라운드마다 목표 손님 수가 고정된다.
- VRAM은 **소프트 제약(1B)**: 예산 초과해도 생산 가능, 대신 생산 속도 저하 + 정산 점수 감소.
- VRAM은 **생산마다 소모(2B)**: 슬롯 칩 cost 합을 누적하고, 라운드 종료 시 리셋.
- 라운드 종료 시 납품 성공률·VRAM 효율·이탈·예산 준수로 100점 환산 후 S~D 등급과 크레딧을 지급한다.
- 저장 스키마를 `version: 2` (`activeRoundId`, `completedRoundIds`, `bestRoundScores`)로 올린다.

## 2026-07-30 (Overcooked 개편)

- 공장 그래프(포트 드래그 DAG) 플레이를 **폐기**하고, **1A + 2B**로 전환한다.
  - 1A: WASD 캐릭터 + E 상호작용으로 주문서/칩/이미지를 운반한다.
  - 2B: 모듈은 선반 칩을 집어 입력~출구 사이 슬롯에 꽂는다.
- 입력기·출구는 스테이션이며 칩이 아니다. 플레이어가 꽂는 것은 중간 모듈(+ 그림 제작기)이다.
- 손님이 프롬프트를 가져오고, 플레이어가 이미지를 다시 전달하는 것이 핵심 루프다.
- 동시 손님은 MVP에서 최대 2명, 인내심 바를 표시한다.
- 결정적 `GenerationSimulator` / `OrderEvaluator`와 O01~O06 데이터는 유지한다.
