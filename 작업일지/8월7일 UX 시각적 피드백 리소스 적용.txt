제목: 8월7일 UX 시각적 피드백 리소스 적용

==================================================
1. 발견한 주요 UX 문제
==================================================
- 상호작용 가능 대상이 하이라이트/!만으로 약하게 구분됨
- 키가 Z인데 E/Space 스타일 키캡이 없고 텍스트 힌트 수준
- 들고 있는 아이템(주문서/칩/폴라로이드) 실루엣·HUD 아이콘 동기화 부족
- 아이템을 어디에 넣어야 하는지(입력기/슬롯/손님) 월드 단서 부족
- 슬롯 EMPTY/AVAILABLE/OCCUPIED, 생산 READY/BUSY/DONE 상태등이 약함
- 생산 완료·픽업·실패에 대한 INPUT→REACTION→RESULT 피드백이 부족
- 손님 인내심이 위험 단계에서만 강조되지 않음
- 초반 동선(손님→입력→칩→생산→출구→손님) 유도가 약함

5. 각 개선이 해결하는 UX 문제
==================================================
1) 무엇과 상호작용? → soft glow + highlight + 단일 [Z]
2) 지금 무엇을? → guide arrow + READY/가져가기 라벨
3) 무엇을 들고? → 플레이어 위 아이콘 + HUD 동일 아이콘/실루엣
4) 어디에 넣지? → carry cue tint + slot available
5) 성공했나? → pickup/insert/success/error FX
6) 생산 중? → busy 텍스처·램프·진동·스파크·진행%
7) 결과 준비? → output ready + 폴라로이드 bounce
8) 손님 인내심? → 바 색 단계 + sweat + 위험 흔들림
